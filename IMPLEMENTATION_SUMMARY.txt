2. INTELLIGENT COURSE MATCHING SYSTEM
──────────────────────────────────────────────────────────────────────────────

Created: src/modules/academics/course-matcher.ts

Implements fuzzy matching algorithms to handle different course code formats:

Key Functions:
  ✓ normalizeCourseCode()      - Standardizes course codes
  ✓ matchCourseCodes()         - Exact matching with normalization
  ✓ extractCourseCodeFromMoodle() - Extracts codes from Moodle text
  ✓ findMatchingCourse()       - Find exact match in a list
  ✓ findBestMatch()            - Fuzzy matching with similarity scores

Handles formats like:
  • "BIO F101" (BITS format)
  • "BIOF101" (Moodle format)
  • "BIO_F101" (alternative)

Uses Levenshtein distance algorithm for similarity scoring.

3. COURSE SEEDING SCRIPT
──────────────────────────────────────────────────────────────────────────────

Created: scripts/seed-courses.ts

Comprehensive seeding script that:
  1. Loads all courses from all_courses.json (~5000+ courses)
  2. Loads handouts from handouts.json (~1800+ handouts)
  3. Matches handouts to courses using fuzzy matching
  4. Inserts or updates courses in the database
  5. Provides detailed progress tracking and statistics

Usage:
  bun run seed:courses

Features:
  • Progress indicators every 100 courses
  • Error handling with error tracking
  • Upsert logic (insert new, update existing)
  • Final statistics report

4. ENHANCED MOODLE SYNC SERVICE
──────────────────────────────────────────────────────────────────────────────

Updated: src/modules/academics/academics.service.ts

Enhanced the syncCoursesWithToken() function with intelligent matching:

Flow:
  1. Fetch courses from Moodle API
  2. Extract course code from Moodle course name/shortname
  3. Search database for matching courses (from seeded catalog)
  4. If match found:
     - Link Moodle course to existing course (set moodleCourseId)
     - Preserve BITS catalog data (name, units, type, handouts)
     - Update with Moodle-specific data (description, resources)
  5. If no match found:
     - Create new course from Moodle data
  6. Create user enrollments
  7. Sync course resources (PDFs, slides, videos)

Benefits:
  • Merges BITS catalog data with live Moodle data
  • Preserves handout links from handouts.json
  • Maintains course metadata (units, type, instructor)
  • Prevents duplicates through intelligent matching
