# Real Streaming Fix

## Problem

The streaming endpoint was sending all chunks at the same timestamp, making it appear like fake streaming:

```
23:01:44.802  chunk {"text":" are"}
23:01:44.802  chunk {"text":" designed"}
23:01:44.802  chunk {"text":" to"}
23:01:44.802  chunk {"text":" produce"}
```

All chunks had the same timestamp because we were:
1. Waiting for the **complete response** from Vertex AI
2. Splitting it into words manually
3. Sending them all at once

This was **simulated streaming**, not real streaming from the AI model.

## Root Cause

```typescript
// OLD CODE - Fake streaming
const result = await chat.sendMessage(query); // Wait for complete response
const text = result.response.candidates[0].content.parts[0].text;

// Split into words and send all at once
const words = text.split(' ');
for (const word of words) {
  yield { type: 'chunk', data: { text: word } }; // All sent instantly
}
```

## Solution

Now using Vertex AI's **real streaming API** (`sendMessageStream`):

```typescript
// NEW CODE - Real streaming
const streamResult = await chat.sendMessageStream(query);

// Process chunks as they arrive in real-time
for await (const chunk of streamResult.stream) {
  const chunkText = chunk.candidates?.[0]?.content?.parts?.[0]?.text;
  if (chunkText) {
    yield { type: 'chunk', data: { text: chunkText } }; // Sent as received
    await sleep(20); // Small delay for natural cadence
  }
}
```

## Implementation Details

### Challenge: Agent Loop with Function Calling

The agent loop is complex because it needs to:
1. Send message
2. Check if response has **function calls** (tools to execute)
3. If yes, execute tools and send results back
4. If no, it's the final text response

**Problem**: We need to collect the complete response to check for function calls, but we want to stream the text in real-time.

### Solution: Smart Streaming

```typescript
async function sendWithStreaming(message, context) {
  // Use streaming API
  const streamResult = await chat.sendMessageStream(message);

  let hasText = false;
  let hasFunctionCalls = false;
  const textChunks = [];

  // Collect chunks and check for function calls
  for await (const chunk of streamResult.stream) {
    const chunkText = chunk.candidates?.[0]?.content?.parts?.[0]?.text;
    if (chunkText) {
      hasText = true;
      textChunks.push(chunkText);
    }

    // Check for function calls in this chunk
    const parts = chunk.candidates?.[0]?.content?.parts || [];
    if (parts.some(p => p.functionCall)) {
      hasFunctionCalls = true;
    }
  }

  return {
    response: await streamResult.response,
    textChunks,
    shouldStream: hasText && !hasFunctionCalls, // Only stream if no tools needed
  };
}
```

### Streaming Logic

```
┌─────────────────┐
│  Initial Query  │
└────────┬────────┘
         │
         ▼
┌─────────────────────┐
│ sendMessageStream() │
└────────┬────────────┘
         │
         ▼
┌──────────────────────┐
│ Collect all chunks   │
│ Check for function   │
│ calls                │
└────────┬─────────────┘
         │
    ┌────┴────┐
    │         │
    ▼         ▼
Has Tools   No Tools (Final Response)
    │         │
    │         ▼
    │    ┌──────────────────┐
    │    │ Stream chunks to │
    │    │ user in real-time│
    │    └──────────────────┘
    │         │
    ▼         ▼
Execute     DONE
Tools
    │
    ▼
Loop back
```

## Code Changes

### Before (Fake Streaming)
```typescript
// Wait for complete response
let result = await chat.sendMessage(query);

// ... agent loop with function calls ...

// Final response - fake streaming
const text = result.response.candidates[0].content.parts[0].text;
const words = text.split(' ');
for (const word of words) {
  yield { type: 'chunk', data: { text: word } };

```

### After (Real Streaming)
```typescript
// Use streaming API
const { response, textChunks, shouldStream } = await sendWithStreaming(query, 'initial');

// If it's final response, stream it
if (shouldStream) {
  for (const chunkText of textChunks) {
    yield { type: 'chunk', data: { text: chunkText } }; // Real-time chunks
    await sleep(20); // Natural cadence
  }
  return; // Done
}

// Otherwise continue agent loop with function calls
// ... execute tools, send responses, repeat ...
```

- Streaming uses same quota as non-streaming
- Retry logic still applies (1s → 2s → 4s backoff)

## Caveats

### Function Calling Iterations

During tool execution, we can't stream because we need to:
1. Check if response has function calls
2. Parse the function calls
3. Execute tools
4. Send results back

Only the **final response** (no more function calls) is streamed in real-time.

### Chunk Delay

Added 20ms delay between chunks for natural cadence:
```typescript
await sleep(20); // Prevents chunks appearing too fast
```

This is minimal and improves UX. Can be adjusted or removed if needed.
